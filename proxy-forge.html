Symbols

Your own mana symbols

Upload an image for any symbol code. Use an existing code like B, 2 or T to replace the built-in drawing, or a new one like HEART and type {HEART} in your text. Transparent PNGs or SVGs look best. Your symbols are saved in this browser and used on every card.

Set symbol and rarity

The set symbol shows at the right end of the type line. In a custom layout, add a “Set symbol (rarity)” layer to place it anywhere.
Export
