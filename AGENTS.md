# Repository instructions

- Work on a branch and open a pull request; never push directly to `main`.
- Before opening a pull request, run `npm run verify` and `npm run real-cards`.
- Never commit or publish `godzilla-series.md`, `playtest guides.txt`, `RECOMMENDATIONS.md`, `references/`, or `art/`. These paths are intentionally git-ignored; do not force-add them or include them in deployment artifacts.
- Never add a `Co-Authored-By` line naming a tool you are not.
